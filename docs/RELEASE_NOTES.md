First public source release of Greek Coast for XScreenSaver on Linux/X11.

- Greek island coastline with clear animated water and a configurable Greece day/night cycle.
- Fishing kaiki, island ferry and sailing caique, appearing one at a time.
- Village activity, hillside taverna and optional small Mediterranean fish shoals.
- Compact settings with preset acceleration choices.
- Standard system and user-local installation, registration and uninstall support.
- MIT project license, included artwork, and third-party license notices.

Download the source archive, extract it, and follow README.md for dependencies and installation. No image-generation service or API key is required. This is a source release, not a prebuilt binary package.

Known limitation: Escape-to-preview recovery has additional handling and automated X11 coverage, but the exact interaction on the original desktop/hardware has not been verified. Native Wayland support is not provided.
